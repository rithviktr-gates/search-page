# Connect — Search page prototype

Static prototype of the unified Search / AI Search page.

## Publish with GitHub Pages

1. Create a new repo and push the contents of this folder to the repo root (`index.html` must be at the top level).
2. Repo → Settings → Pages → Source: **Deploy from a branch**, Branch: `main`, Folder: `/ (root)`.
3. Wait a minute, then open `https://<user>.github.io/<repo>/`.

`.nojekyll` is included so GitHub serves all files as-is.

## Files

- `index.html` — the page
- `support.js` — runtime that renders it
- `images/`, `uploads/` — image assets used by the page

Requires an internet connection (fonts/runtime libraries load from CDNs).
