# Connect — Home + Manage Membership

Static prototype. `index.html` is the Connect web home; notifications are the bell dropdown in the header. The header **Membership** tab opens `membership.html`, and **Home** there returns to the feed.

## Publish with GitHub Pages
1. Push the contents of this folder to the repo root (`index.html` at top level).
2. Settings -> Pages -> Deploy from a branch -> `main` / `/ (root)`.
3. Open `https://<user>.github.io/<repo>/`.

`.nojekyll` is included so all files are served as-is. Fonts load from Google Fonts, so keep a connection.
